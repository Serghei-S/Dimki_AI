# Центр Обнинска: карта и расчётная модель

Приложение по умолчанию открывает центральный участок вокруг площади Преображения, проспекта Ленина, улиц Лейпунского, Красных Зорь, Осипенко и Кончаловского. Прежний «Сосновый» доступен через переключатель «Территория». При переключении в текущем сеансе сохраняются изменения и история отмены каждого района. Сохранённые сценарии разделены по территории; прежние записи в браузере сохраняются.

## Состав

- 41 основное здание с реальными контурами, включая 36 условно жилых; 3 692 моделируемых жителя.
- 31 фрагмент проезжей части по реальным осям улиц, включая изгибы и кольцевое движение.
- 15 отмеченных OSM точек переходов. В графе это 21 активное ребро пересечения проезжей части: отдельные стороны и проезжие части могут иметь собственные участки.
- 4 остановки и 3 продуктовых магазина из OSM, школа № 5, здание администрации и гостиница «Юбилейная».
- 3 зелёные площадки по контурам OSM-газонов. Их использование как доступной зелёной зоны — учебное допущение, не утверждение официального статуса парка.
- 12 условных проектов, 6 сценариев и 3 профиля движения. Новые переходы и скверы остаются предложениями, не существующими или утверждёнными объектами.

Исходная рамка: 36.6072–36.6170° E, 55.0900–55.0945° N. Полные контуры выбранных зданий сохраняются, даже если выступают за рамку отбора. Координаты переводятся из WGS84 в локальные метры без растягивания или перестановки домов. Высота берётся из `height`, этажность — из `building:levels`, если они заполнены; оценочные значения помечаются знаком ≈ в карточке. Карточка содержит ссылку на исходное здание OSM.

## Что является допущением

Это гибридная модель: реальные контуры и названия соединены с явно обозначенными учебными параметрами. Поле `metadata.synthetic: true` сохраняется, поскольку население и расчётные параметры не являются измерениями.

Население определяется через площадь здания, этажность, долю полезной площади 0,78, условную квартиру 55 м² и заселённость 94%. Состав домохозяйств генерируется детерминированно по ID здания. Число жителей, возрастные группы и домохозяйства согласованы арифметически. Это не сведения о жильцах конкретных домов. Использование части зданий с OSM-тегом `building=yes` как жилых также является допущением.

Подтверждённой поликлиники в выбранном фрагменте OSM нет. Поэтому исходный «Учебный медпункт · сценарное допущение» явно обозначен как модельный объект. Его можно удалить, перенести или заменить через редактор. Магазины с `shop=alcohol` не используются как продуктовые цели; продуктовые объекты взяты из `shop=supermarket/convenience`.

Пешеходная сеть использует OSM-дорожки и доступные дворовые проезды. Неотмеченные тротуары приближённо строятся по обеим сторонам реальных осей улиц. Короткие связи между компонентами допускаются до 45 м, если не пересекают здания и проезжую часть. Зазоры оцифровки ремонтируются до 0,35 м; совпадающие узлы объединяются в пределах 0,05 м. Переходы через проезжую часть разрешены только на отмеченных OSM-переходах/пешеходных пересечениях либо после включения отдельного проекта нового перехода.

Неотмеченные входы домов приближены к доступной стороне здания. Известные OSM-входы используются при наличии. Если магазин расположен внутри жилого здания, путь заканчивается у входа здания, а не в центре его контура. Бордюры, ширина дорожек, уклоны и ожидания переходов не обследованы: в модели это параметры сравнения, не подтверждение безбарьерности маршрута. Заборы и права прохода не сертифицированы. Уличные остановки привязаны к тротуару на своей стороне; реальное автобусное расписание не моделируется.

Граница участка обрезает сеть. Маршруты за пределами рамки не учитываются. Добавление реальной географии не превращает результаты в официальный прогноз или навигатор.

## Файлы и воспроизводимость

| Файл | Назначение |
|---|---|
| `data/obninsk-center.json` | Канонический новый набор, загружаемый сайтом |
| `data/obninsk-center.provenance.json` | Происхождение зданий, этажности, входов, рёбер и объектов; SHA-256 источников |
| `data/obninsk-center.manifest.json` | Контрольные суммы нового набора и производных файлов |
| `data/sources/obninsk-center.osm.json` | Сохранённый ответ Overpass от 16.10.2026 |
| `data/sources/obninsk-center.overpass` | Точный запрос первого снимка |
| `data/sources/obninsk-details.osm.xml` | Ответ OSM API 0.6 для газонов, входов и дополнительных деталей |
| `data/sources/obninsk-details.osm.json` | Фильтрованный результат из сохранённого XML |
| `data/obninsk/geojson/` | Экспорт геометрии в WGS84 с атрибуцией и лицензией |
| `data/obninsk/reports/` | Геометрический аудит и независимые Python-расчёты всех сценариев |
| `data/obninsk/preview/plan.png` | Автономный обзор для проверки и экспорта |

Сайт работает с локальным снимком и не обращается к OSM/Overpass во время обычной работы. Для запуска браузерного приложения Python не нужен. Для пересборки данных нужен Python с зависимостями `tools/requirements-geo.txt`; в подготовленной среде они находятся в `.tools/geo`.

```powershell
python -m pip install -r tools/requirements-geo.txt
python tools/build_obninsk.py
python tools/validate_obninsk.py
pnpm verify
pnpm build
```

`tools/build_obninsk.py` не делает сетевых запросов и проверяет геометрию до замены канонического файла. Для сознательного обновления снимка: `python tools/fetch_obninsk.py --refresh`, затем пересборка и проверки. Без `--refresh` используются сохранённые ответы. При публикации обновлённой географии следует поднять `datasetVersion`; SHA-256 сценария дополнительно защищает от применения к другому содержимому.

Геометрические проверки проходят по всем шести сценариям: корректные полигоны, совпадение концов полилиний с узлами, длины, отсутствие путей сквозь здания и пересечений проезжей части вне переходов, отсутствие геометрических пересечений дорожек без узла графа. Численные результаты JavaScript сравниваются с независимым Python-эталоном.
