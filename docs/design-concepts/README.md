# Варианты оформления

Пять визуальных концептов сгенерированы 17 октября 2026 года встроенным image_gen
на основе географического плана `data/obninsk/preview/plan.png`. Полные промпты
хранятся в `prompts.json`.

1. `01-light-gis.png` — Светлый GIS. Выбран для реализации.
2. `02-dark-analysis.png` — Тёмный аналитический.
3. `03-architectural-atlas.png` — Архитектурный атлас.
4. `04-civic-modernism.png` — Городской модернизм.
5. `05-engineering-plan.png` — Инженерный план.

Это иллюстрации направлений дизайна, не снимки рабочего интерфейса и не
достоверные картографические материалы. В сборку приложения не включаются.
Реализация выбранного варианта описана в `../LIGHT_GIS.md`.
